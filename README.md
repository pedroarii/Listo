# Listo

Unified grocery list: it combines the ingredients for your weekly meals with the household items you need, subtracts what you already have on hand, and organizes everything by store section.

O Listo nasceu de um problema pessoal: a lista de mercado vive espalhada entre receitas, o bloco de notas e a memória. Ele junta tudo numa lista só. Você escolhe as receitas da semana, o app soma os ingredientes, inclui os itens recorrentes da casa (café, detergente, papel higiênico), deixa você desmarcar o que já tem e converte as quantidades em embalagens reais (“1 bandeja de frango”, não “900g”). Cada item sabe de onde veio, então mudar a semana recalcula a lista sozinha.
